# Privacy Policy for ClassPulse

*Last Updated: May 2026*

## Overview

ClassPulse is a Chrome extension designed to help students organize Canvas LMS assignments, receive deadline reminders, and improve productivity.

This Privacy Policy explains what information ClassPulse accesses, how it is used, and how user privacy is protected.

---

# Information We Access

ClassPulse may access the following information solely to provide extension functionality:

* Canvas LMS course information
* Assignment titles and deadlines
* Assignment links and metadata
* User reminder preferences
* Canvas access tokens (if provided by the user)

This information is used only for displaying assignments, generating reminders, and improving the user experience inside the extension.

---

# How Information Is Stored

ClassPulse stores user settings and assignment data locally within the user's browser using Chrome Extension Storage APIs.

No educational data is sold or shared with third parties.

---

# Data Usage

ClassPulse uses accessed information exclusively for:

* Assignment tracking
* Deadline reminders
* Course organization
* One-click assignment access
* Student productivity features

ClassPulse does NOT:

* Sell user data
* Share personal information with advertisers
* Use tracking cookies
* Perform behavioral advertising
* Collect unrelated browsing history
* Record keystrokes or personal communications

---

# Authentication Information

If the user provides a Canvas access token or authentication credential, it is stored locally within the browser and used solely for secure communication with the user's Canvas LMS instance.

Authentication information is never sold or transferred to external parties.

---

# Third-Party Services

ClassPulse may communicate directly with the user's Canvas LMS instance to retrieve assignment and course information.

ClassPulse does not use third-party analytics or advertising networks.

---

# Data Security

Reasonable security measures are implemented to protect locally stored information.

However, users are responsible for securing their own browser profile and device access.

---

# Children's Privacy

ClassPulse is intended for general educational use and does not knowingly collect personal information from children under 13.
